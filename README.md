# YW2 Editor for Android

「妖怪ウォッチ2 元祖・本家・真打」の `game*.yw` をAndroid上で復号・編集・再暗号化するブランチです。

## 対応内容

- 真打、および元祖・本家 1.x の `game*.yw` を直接読み込み
- 元祖・本家 2.x は `head.yw` からAES-CCMキーを導出して読み込み
- 妖怪の種類、ニックネーム、レベル、技レベル、性格、まじめ度、個体値(IV)、育成値(EV)を編集
- どうぐ、そうび、だいじなもの、魂の種類・数量等を編集
- 所持金を編集
- 日本語の妖怪/アイテム/装備/魂マスターデータを同梱
- 保存前に暗号化→再復号→セーブ構造の再解析を実施
- 保存時に元データをアプリ内部 `files/yw2-backups/` へバックアップ

## 使い方

1. 3DS/エミュレータから `game*.yw` を取り出す
2. 元祖・本家 2.x の場合のみ、先に「head.yw」から同じセーブの `head.yw` を選ぶ
3. 「game*.ywを開く」で編集対象を選ぶ
4. 各タブから編集し、「保存」で元の `game*.yw` に書き戻す
5. 3DS/エミュレータ側へセーブを戻す

## 実装根拠

YW2の暗号・復号、レコード配置、マスターデータは `atuy1219/ykw-editors`（元の togenyan / nobody_fear 系実装）を参照してKotlinへ移植しています。特に `python-tools/yw_save.py`、`my-editor/2/dump2.py`、`source-code/2` を参照しています。

## 注意

セーブ破損に備えて、編集前のファイルは別途保管してください。元祖・本家 2.x では `game*.yw` と対応する `head.yw` の組み合わせが必要です。
